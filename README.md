## <ins>Description</ins>  
What we sought to develop for this project was a WEB and API for E-commerce, which handles different types of authenticated sessions with JWT. The client user can only buy and manage their personal data, managers can manage clients and products, and finally admins can do everything mentioned above, in addition to managing other admins, managers and accessing the API documentation.  
  
This project includes CRUD for different types of users (Admin, Clients and Managers), products, carts, orders and payment methods which are only to simulate a purchase, their functionality is not 100% worked on because it is more useful and secure to use some external technology focused on this sector, for example Mercado Pago.
  
The endpoints are secured by Spring according to user role, the web includes navigation of all endpoints through an intuitive interface oriented to a PC components E-commerce.
